# Beneath a Typographic Sky

Asciiverse point-and-click adventure. Rust + Ratatui.
Terminal take on Revolution Software's Beneath a Steel Sky (1994).

**Status (2026-10-17):** playable. A Rust port of ScummVM's sky engine
runs the original CD data (v0.0372) and draws it in the terminal:
truecolour Braille (160x50 cells, one dot per game pixel) or half blocks
on terminals of 320x100 and up (F2 switches), game text set as real type
over the picture, mouse through the terminal. Sound effects, speech and
AdLib music (Nuked OPL3) are connected. Checked headless: the opening
plays through (take the rung, pry the door, the guard's lines, room 1).
The intro is being ported; until then the game starts at the restart
point. Own git repo, not on GitHub yet.

## Name

Beneath a Steel Sky → Beneath a Typographic Sky. The swap names the medium:
the city of Union City rebuilt out of characters. It reads as a clear tribute
and explains the concept without needing context.

The title stays close to the original, so it depends on Revolution being
comfortable with it. Cover the name explicitly in the outreach email.
Collision check not yet done.

  6. As-is, no warranty.
  The preamble adds: commercial adventure game collections should ask first.
- Related: 2009 iOS remaster, and the sequel Beyond a Steel Sky (2020).

## Legal approach (updated 2026-10-17 from the license above)

- **Bundling the data files** with the engine: allowed (clauses 1 and 2),
  keep readme.txt beside them. Asciiverse is free, so clause 3 is met.
- **Converted or redrawn art we distribute:** allowed as a modified version
  (clause 4), with a prominent "modified version" notice (title screen and
  NOTICE file). The old note that this needed Revolution's approval was
  wrong.
- **Never sold.** If Asciiverse paid titles come later, this one stays free.
- **The name:** the license says nothing about names or trademarks, so a
  courtesy blessing from Revolution is still the right move before
  announcing.

## Code

The crate is GPL-3.0-or-later because the engine is a port of ScummVM's
GPL code (engines/sky), kept faithful, workarounds and their comments
included. Confirmed by David 2026-10-18; `LICENSE` is the GPL v3
text from gnu.org. The game data stays under Revolution's freeware
licence (`readme.txt`, shipped beside it); see `NOTICE`.

- `src/engine/`: the engine. All of ScummVM's sky classes are one `Sky`
  struct (sky.rs); each original class is an `impl Sky` file: logic.rs
  (interpreter, logic modes), mcode.rs (the 115 script functions),
  screen.rs, text.rs, mouse.rs, grid.rs, autoroute.rs, cache.rs,
  control.rs (restart, save format identical to ScummVM's SKY-VM.nnn),
  sound.rs, music/, intro.rs. Compacts live in one word buffer as in the
  original (cpt.rs); `Sky::elem` maps script element offsets.
  defs.rs and hufftext.rs are generated by tools/gen_defs.py and from
  hufftext.cpp.
- `src/engine/host.rs`: the `Host` trait (time, input, present, menus),
  ScummVM's OSystem. `Headless` for tests and tools.
- `src/term/`: the terminal host (app.rs) and the rasteriser (raster.rs).
- The options panel is a terminal menu (F5 or q), not the game's pixel
  panel. Saves go to `$XDG_DATA_HOME/typographic-sky/`.
- Start (David, 2026-10-17): the intro plays on the first launch only
  (`intro-seen` in the save folder); after that a start menu offers
  Continue, Restore a game, New game, Watch the intro. Quitting autosaves
  to slot 0 (`SKY-VM.000`, ScummVM's autosave slot), except on the death
  screen or while the game forbids saving. `--skip-intro` goes straight
  to a new game.
- Pixel buttons are labelled in type (`UI_BUTTONS` in screen.rs): the
  death screen's three panels, the inventory arrows and the LINC info
  panel's smiley button ("Close"). David's
  rule: the same treatment wherever the game draws UI as pixels, listing
  each new case before changing it.
- Game text is set in terminal type by default (David, 2026-10-18: the
  game's pixel font reads worse at normal sizes). `--game-font` keeps the
  game's own fonts as Braille dots, for very high resolution screens;
  button labels stay typed either way.
- Language (David, 2026-10-18): the one chosen in F5 before (saved as
  `language` in the save folder), else the system locale, else English;
  all eight CD languages display correctly through the font table;
  speech is English only.
- Pointer snapping (David, 2026-10-18): on coarse terminals, a cell that
  covers part of a hotspot while its middle misses snaps onto it
  (`Sky::snap_pointer`, `Host::pointer_reach`), so thin hotspots stay
  clickable at any size.
- Inventory and LINC menu icons stay pictures (drawn in quadrant blocks
  while the bar is open), with their names in type on hover; David,
  2026-10-18: "good as they are with the overlay text".
- Controls: left click looks, right click uses (as in BASS and ScummVM);
  pointer to the top edge opens the inventory; Esc skips, `.` skips a
  line, p pauses, F2 render mode, Ctrl+F fast mode, Ctrl+C quits.
- Tools: `typosky dump|look|headless|probe|text|monkey|sfx|speech|music`
  (see `typosky help`). `headless 600 1 out 5:23,70,1` plays scripted
  clicks (cycle:x,y,button; button 0 moves only) and saves frames.
  `tools/ansi2png.py` turns a `tmux capture-pane -e -p` into a PNG.
- Walkthrough driver (src/walk.rs): `typosky walk walkthrough/to-linc.txt
  --until-linc` plays a script of steps (`use metal bar on door`, `talk
  joey`, `choose transporter` ...) headless in about a second, printing a
  transcript, and writes its saves to `walkthrough/saves/` (SKY-VM.001 to
  .007, from the walkway to the first LINC entry). `--load=<save>
  --from=<line>` goes on from a save; `walkthrough/linc-ui.txt` tours the
  LINC's pixel interface from save 7.
- Checked against ScummVM 2026.1 (2026-10-18): a click that starts
  Foster's walk and then gives up when another character crosses his
  path (Lamb after the ticket, room 20) is the original's behaviour;
  ScummVM stops him at the same spot. Same click 8 s later: both leave
  the room. `typosky trace <save> <x> <y> <button> <cycles> [at]` prints
  Foster and Lamb per cycle after one click.
  LINC's pixel interface from save 7. `walkthrough/to-end.txt` plays on
  from save 7 to the end credits (about 58000 cycles, two seconds),
  saving SKY-VM.008 to .023 at the story points; its comments name the
  script variables the walkthroughs leave out. For digging into a stuck
  scene: `RUST_LOG=script=trace,mcode=trace` traces every script command
  and mcode call, and the walker's `vars`, `words`, `disasm`, `writes`
  and `seq` steps read variables, compacts and the script modules.
- Data: `reference/bass-cd-1.2/` (gitignored), or `TYPOSKY_DATA`.
- Session log: `RUST_LOG=debug typosky 2>typosky.log`.

## Rendering approach (original notes, 2026-10-03; see Status for what was built)

This is a bigger aesthetic leap than Another Rift. The source is dense,
colourful pixel art, with backgrounds by comic artist Dave Gibbons, not
vector polygons.

- **Drawille (Braille sub-pixel):** backgrounds and sprites, converted from
  bitmaps at runtime. Will likely need dithering, edge detection and
  palette-to-contrast mapping to stay readable. Expect real iteration here.
- **Ratatui:** the adventure UI. Verbs, inventory, dialogue and text are a
  natural fit for a terminal, arguably more so than the visuals.
- Consider colour terminals (truecolor Braille) vs monochrome as an option.
