# Beneath a Typographic Sky

Revolution's Beneath a Steel Sky in the terminal: Union City rebuilt out of Braille dots, its words set in type.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install beneath-a-typographic-sky
av play beneath-a-typographic-sky
```

## Credits

Revolution Software made Beneath a Steel Sky in 1994 and released it as
freeware in 2003. This edition plays the unmodified CD version in a Rust
port of ScummVM's engine, drawing the pictures in Braille dots and setting
the game's text in type, a modified version as Revolution's licence allows.
It is free and never sold.
