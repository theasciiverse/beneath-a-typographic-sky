# Beneath a Steel Sky (CD v0.0372), from Foster's first entry into the
# LINC to the end of the game. Run with
#   typosky walk walkthrough/to-end.txt --load=walkthrough/saves/SKY-VM.007
#
# Follows M. Shaw's walkthrough (Game Bytes Magazine issue 21, 1994,
# www.ibiblio.org/GameBytes/issue21/misc/bass.html), checked against
# "The Complete Beneath A Steel Sky Walkthrough" (FOURTYoz, Hitiek, Red,
# OLiVER, 1994; bearstrong.net/tekst97/data/spill/bass/) where Shaw is
# vague. Object names, dialogue lines and the order of things are the
# ones the game actually shows (found with the hotspots step); where the
# walkthroughs skip a condition the game's scripts check, the comment
# says which script variable it is (names from ScummVM's debug.cpp).
#
# Steps: look/use/take/talk/exit <thing>, use <item> on <thing>,
# choose <part of a line>, waitfor/waitgone <thing>, wait <cycles>,
# settle, save <slot> <name>. `@name` is a compact's own name, for things
# with no text or the same text twice. `waitvar <n> <value>` waits for a
# script variable (13 is the mouse status: 6 when the player has control)
# and `quick <step>` does not wait for things to settle, for the races.
# See src/walk.rs.
